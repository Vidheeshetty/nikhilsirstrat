Data Conversion Tools

Overview

The project ships utility scripts to convert raw CSV option/futures data into the Parquet catalog format required by NautilusTrader.

Conversion Scripts

ScriptDescription
scripts/csv_to_parquet_converter.pyGeneric CSV → Parquet converter supporting contract metadata.
legacy_src/convert_csv_to_parquet_w_meta_fixed_v5.pyLegacy converter kept for regression matching.

Usage

python scripts/csv_to_parquet_converter.py \
       --input data/options/nse/nifty/NIFTY_2025-06-23.csv \
       --output catalog-data/shared/catalog

Validation

Run the following tests to ensure converted data meets schema expectations:

pytest tests/utils/test_converter_*.py
