Paper-Trading Setup

Overview

Paper trading allows you to validate a strategy in real-time without risking capital. Orders are routed to a simulated exchange environment.

Setup Steps

  1. Update your API credentials in config/paper_trading.yaml.
  2. Start the runner: 
    python scripts/run_paper_trading.py --strategy trend_riding
  3. Monitor orders via the command-line output or connect to the WebSocket dashboard.

Logs & Monitoring

Paper-trading logs are stored under logs/paper/. Each session generates:

  • orders.log – order submission & fills
  • positions.log – current positions snapshot every minute
