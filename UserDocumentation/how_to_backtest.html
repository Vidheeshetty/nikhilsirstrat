Running Back-tests

Overview

Back-testing simulates historical trades to gauge a strategy's performance before live deployment. Our platform provides both single-instrument and batch-mode runners.

Quick Start

  1. Ensure your Python environment is activated and dependencies installed:

    pip install -r requirements.txt

  2. Run a single instrument test:

    python scripts/run_backtest.py --instrument NIFTY20250627.FUT.NSE \
                               --strategy trend_riding

  3. Batch mode across multiple symbols:

    python scripts/run_batch_backtest.py --strategy trend_riding \
                                     --symbols-file data/symbols_nifty.txt

Understanding Output

Results are written to backtest_results/ and include:

  • summary.json – metrics per instrument
  • aggregated_results.json – portfolio-level statistics
  • HTML reports under reports/html_reports/
