Trend-Riding Strategy Guide

Overview

The Trend-Riding strategy seeks to capture sustained market moves by entering positions when price momentum and volatility align. It is implemented in src/strategies/trend_riding.

Architecture

  • Strategy Class: TrendRidingStrategy
  • Config: TrendRidingConfig (look-back, SL/TP, etc.)
  • Helpers: entry.py, risk.py, position.py

Execution Workflow

When plugged into a back-test runner or live engine, the strategy receives quote events and evaluates entry/exit conditions as follows:

  1. Accumulate quotes until lookback_intervals satisfied.
  2. Detect breakout using entry.should_enter.
  3. Place market order and track stop-loss / take-profit via RiskManager.
  4. Exit when risk conditions met or session ends.

Key Parameters

ParameterDescriptionDefault
lookback_intervalsBars to evaluate for trend breakout.20
sl_pctStop-loss distance as %.1.5
tp_pctTake-profit distance as %.3.0

Example Usage

from strategies.trend_riding.runner.backtest_runner.single_runner import TrendRidingBacktestRunner

runner = TrendRidingBacktestRunner()
result = runner.run("NIFTY20250627.FUT.NSE")
print(result)
